# Bumper contact: earlier model

The original desktop bumper study used a rigid shell. The current Full3D setup uses a compliant foam and rigid backing model; start with [simulated bumper contact](compliant-bumper-contact.md).

- The earlier study explored terrain contact, bumper geometry, and collision behavior.
- Its values and results describe a historical setup, not necessarily the current robot model.
- Neither study replaces physical measurement or inspection.

For the original geometry, assumptions, and test evidence, see the [historical bumper record](reference/bumper-contact.md). The current season settings are in [RobotContainer.cpp](../src/main/cpp/RobotContainer.cpp).
